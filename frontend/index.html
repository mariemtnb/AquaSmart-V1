ℹ️ About AquaSmart
🎓 Project Information

Module: PDL — I4_881 | ING4 Semestre 2

School: SESAME — École Supérieure Privée des Sciences Appliquées et de Management

Supervisor: Louay Tanazefti

Objective: Optimize fish feeding using environmental IoT sensor data and machine learning to reduce waste and improve fish health.

🤖 ML Pipeline
✅ Multi-source IoT pond data loading
✅ Data cleaning & outlier removal
✅ Feature engineering (WQI, stress indices)
✅ Mutual information feature selection
✅ RobustScaler preprocessing
✅ Gradient Boosting regression model
✅ Rule-based + ML hybrid advisor
✅ Domain-trained chatbot (no API key)
✅ FastAPI REST backend + live dashboard
⚗️ Feeding Strategies
STOP ×0.0 Critical conditions (temp <12°C or >35°C, DO <3, ammonia >0.06)
REDUCE ×0.55 Suboptimal — reduce feeding 45%
NORMAL ×1.0 Acceptable conditions — normal feeding
INCREASE ×1.1 Excellent conditions — increase 10%

🌐 Federated Learning
Privacy-preserving distributed training across all fish ponds
How it works
Each fish pond acts as a private client. Raw sensor data never leaves the pond. Instead, each client trains a local model and sends only the model parameters to the central server, which aggregates them using FedAvg. Optional Gaussian differential privacy noise can be added to the gradients before upload.
